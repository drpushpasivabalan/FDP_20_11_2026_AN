Vulnerability Assessment Simulator

Five assessment types, each run through the six-step process: asset identification → scanning → analysis → risk assessment → remediation → verification. Every target and result is simulated in the browser; the Python code panel shows how each check is implemented for real.

Lab rule: run real scans only on systems you own or have written permission to test. Practice on lab targets such as Metasploitable, DVWA or OWASP Juice Shop, never on live campus or third-party systems.
